### 1.3 数据源台账

| 数据 | 来源 | 许可 | 入库？ |
|---|---|---|---|
| 全部证书与私钥 | `fixtures/gen.sh` 现场生成（OpenSSL 3.5.6） | 本项目自造，无第三方权利 | 产物**不入库**（`.gitignore` 挡 `fixtures/out/`） |
| `fixtures/out/manifest.json` | 生成器写出 | 同上 | **不入库**（含时间无关的期望结论，但仍属于产物） |
| 期望结论（真值） | `fixtures/expected.json`（脚本生成，可入库） | 同上 | **入仓**——只含输入描述与期望，不含任何密钥材料 |
| 规范条文 | RFC / CA/B / NIST 原文 | 各自许可 | 只摘录节号与短句，不整篇转载 |

> **关键分野**：`expected.json` 是**真值**（可入库，纯文本、无密钥）；`fixtures/out/**` 是**产物**
> （不入库，含私钥，每次 `gen.sh` 现场生成）。两者不能放同一个目录，否则 `.gitignore` 一挡就把真值也挡掉。

## 二、真值纪律

1. **真值只存"输入 + 期望"，不存"观测"**：
   `expected.json` 里**禁止**出现 `observed_*` / `actual_*` 字段。出现即测试失败
   （`tests/test_fixtures_truth.py` 断言字段名白名单）。
2. **期望值可由输入独立复算**：
   例如 `expired.pem` 的期望是 `EXPIRED`，复算方式 = 从 manifest 的 `not_after` 与用例的 `as_of`
   独立比较，**不读 `hygiene.py` 的输出**。判别：把 `hygiene.py` 注释掉，真值仍然算得出来。
3. **`as_of` 是样本的一部分**：每个用例组声明自己的 `as_of`（固定 Unix 秒），
   **不是"测试跑的时候"**。所有样本的 `not_before/not_after` 相对这个 `as_of` 钉死。
4. **`--as-of` 变更即真值重算**：改 `as_of` 必须同轮重生成 `expected.json` 并重跑全量。
5. **禁止"空真值"通过**：`expected.json` 为空或某用例无期望 → 测试失败（不是 skip）。

## 三、可复现性

- **日期钉死**：`openssl req -x509 ... -not_before <YYYYMMDDHHMMSSZ> -not_after <...>`；
  **序列号钉死**：`-set_serial 0x...`（每个样本固定值，写进 manifest）。
- **同参数两次生成 → 同指纹**（断言：两次生成后 `sha256sum` 所有 `.pem/.key/.crt` 相等）。
- **容器字节不可复现**（P12 salt、JKS 内部时间戳）——因此：
  - **基线比对对象 = 台账 JSON / 报告 JSON+Markdown**，不是容器文件字节（`data/README` §4.4）；
  - 容器样本的"可复现"指**解析结果**可复现（alias 表、指纹列表），不指字节。
- **`gen.sh` 必须支持 `--check`**：重跑到临时目录并与 `fixtures/expected.json` 比对，
  只比"可复现的部分"（指纹、alias 表、期望结论）；容器字节跳过并在输出里明说跳过了几项。
- **生成器部分运行不得改写全集清单**（`--only <case>` 只生成不写 `expected.json` 的全集）。

## 四、数值口径

**唯一权威 = `data/README.md` §五（1–9 条）**。本文只列"样本里用到的具体取值"，用于让样本自解释；
**改这里必须先改 `data/README.md`**，且两边不一致时以 `data/README.md` 为准（有测试断言二者一致）。

| 参数 | 值 | 出处 |
|---|---|---|
| `as_of`（基准） | `1900000000`（2030-03-17T17:46:40Z） | 惯例值；`openssl verify -attime` 本机实测可用 |
| `warn_days`（EXPIRING 窗口） | 30 | 策略文件 `hygiene.expiring.warn_days` |
| `cliff_window_days` | 30 | 同上 |
| `cliff_min_count` | 3 | 同上 |
| RSA 弱密钥阈值 | `< 2048` | CA/B TLS BR §6.1.5；NIST SP 800-131A Rev.2 |
| 允许曲线 | P-256 / P-384 / P-521 | CA/B TLS BR §6.1.5 |
| 弱签名 | SHA-1 | NIST SP 800-131A Rev.2 |
| 口令环境变量 | `CERTLEDGER_PASSWORD`（默认名） | 不落盘、不进报告 |
| 文件上限 | 8 MiB | 策略 `collect.max_file_bytes` |
| 嗅探窗口 | 4096 B | 策略 `collect.sniff_bytes` |

**代码零默认字面量**（K3）：上表所有值只在 `src/certledger/data/default-policy.json` 出现一次，
代码里通过 `policy.loader` 读取。策略文件缺失/字段非法 → 退出码 2。

## 五、测试夹具与隔离

- 用 `tmp_path` 造临时目录；**不写用户主目录**、**不读真实证书存储**（除了显式标 `@pytest.mark.system` 的
  系统后端用例，默认不在 CI 跑）。
- Windows 上 `chmod` **不阻止写入**（不构成权限测试）：`PERMISSION_TOO_OPEN` 的 POSIX 用例用
  `os.chmod` 造，并 `pytest.mark.skipif(os.name == "nt")`；Windows ACL 侧只断言"产 INFO 提示"。
- 每个测试用例前后**不产生仓库内残留**（`git status --porcelain` 为空，CI 有一条断言）。
