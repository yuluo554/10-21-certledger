## 二、风险登记

| 编号 | 风险 | 影响 | 缓解 | 状态 |
|---|---|---|---|---|
| R1 | 与 ChainWarden（77★）被读成同类 | 定位失败，评分"综合表现"归零 | README 首屏**一句话差异句**（D1）；`tests/test_readme.py` 钉住这句 | 已识别，待 M2 落实 |
| R2 | JKS 无 RFC + pyjks 停更 | 容器模块不可靠 | 走 `keytool`（D2）；缺失降级 `CONTAINER_UNREADABLE`；**文档明说无 RFC** | 已定 |
| R3 | 阈值被写成"RSA 2048 已弱"这类事实错误 | 报告在真实环境制造假警报 | D3 口径 + 默认 WARN + `rule_source` 必填 + 文案测试 | 已定 |
| R4 | macOS 后端未实测 | README 若承诺则失信 | D4：恒 `SOURCE_UNAVAILABLE` + `unverified_backend`，README 不列入能力清单 | 已定 |
| R5 | `storeutl winstore` 返回空被误用 | Windows 上产出"空台账"（看起来像没有证书） | D5：走 `certutil`；空存储与后端不可用分两种记录 | 已定 |
| R6 | 容器字节不可复现 | 基线比对假红 | 比对对象限定为台账/报告 JSON（`data/README` §4.4） | 已定 |
| R7 | 面向用户文案引用内部里程碑号会过期 | 提示说谎 | 文案禁令；`tests/test_cli.py` 断言 help/错误信息不含 `M[0-9]` 形态的里程碑引用 | 规则已定，M0 已落 |
| R8 | 骨架期空壳返回空结果 | "看起来成功的错误答案" | 空壳必须抛 `NotImplementedError` → CLI 转 2 | M0 已落 |
| R9 | 零网络承诺被依赖引入破坏 | 隐私口径失信 | AST 守门断言网络模块不被 import | M2 落 |
| R10 | 大目录扫描性能 | 用户放弃使用 | 流式遍历 + 前缀窗口嗅探（4096B）；M2 记录 10k 文件基准 | M2 |
